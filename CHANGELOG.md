# Changelog / 更新日志

## 2.0.2 — 2026-09-27

- **History** · 历史记录：every dictation with the original speech and the cleaned-up text; searchable, one-click copy, 20 per page. Stored only on your computer. / 原话和整理后的文字都在，可搜索、一键复制，每页 20 条，只存本机。
- **Long dictation up to 20 minutes** · 长录音最长 20 分钟：if the final step ever fails on a long recording, the recognized text is still inserted instead of being lost. / 长录音出问题时用已识别的原话保底，不会整段丢失。
- **Progress on the capsule** · 识别进度：the capsule border fills up in blue while your text is being prepared. / 松手后胶囊边框一点点变蓝，出字变绿。
- **My vocabulary** redesigned · 词库新样式：search or add from one field, one word per line.
- **Update notice** in Overview · 概览右上角提示新版本。
- **Esc** now dismisses cards above the capsule; voice-control confirmations are treated as "don't do it". / Esc 能关掉胶囊上的卡片，语音操控的确认卡片按 Esc 等于不执行。
- Windows: clicking ✕ / ✓ on the capsule works reliably. / Windows 上点胶囊的 ✕ / ✓ 更可靠。

## 2.0.1 — 2026-09-26

- Updates install quietly when you're idle or the screen is locked. / 空闲或锁屏时静默更新，自动重开。
- Auto-send is limited to terminals, Claude, Codex and VS Code (chat apps removed: too easy to send by mistake). / 说完自动发送只在终端、Claude、Codex、VS Code 里生效。
- Windows catches up from 1.0.7 to 2.0.x. / Windows 从 1.0.7 升到 2.0.x。

## 2.0.0 — 2026-09-25 (macOS)

- **Voice control** with left ⌥: brightness, volume, open apps and websites, open Terminal, start Claude Code; dangerous actions ask first. / 左 ⌥ 语音操控。
- **Auto-send** after dictation with an adjustable countdown. / 说完自动发送，可设倒数。
- Capsule styles: Classic, Breathing orb, Glass. / 胶囊样式三选一。
- Retry on network errors, copy button when text couldn't be inserted, top-up card when you run out. / 网络问题重试、没输入进去可复制、额度用完提示充值。
- Daily usage chart in Billing (7 / 30 / 90 days or a custom range). / 账单每日用量图。
