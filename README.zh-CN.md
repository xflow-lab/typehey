## 能做什么

- **按住右 ⌥ 说话**（Windows：右 Ctrl）：松手后文字落在光标处，微信、邮件、文档、代码编辑器、终端都能用。
- **说得乱，写得清楚**：嗯、啊、说错改口的地方自动处理，该加标点加标点，该分段分段，说「第一点、第二点」就整理成清单。
- **按住左 ⌥ 控制电脑**（Windows：右 Alt）：「亮度调到三十」「在项目里打开终端、启动 Claude」「锁屏」。关机、重启一定先问你。
- **说完自动发送**：在终端、Claude Code、Codex、VS Code 的终端和 AI 对话框里，出字后倒数几秒自动按回车，按 Esc 取消。
- **我的词库**：加上公司名、同事名字、行业术语，下次就能认对，只对你自己生效。
- **历史记录**：每次说的原话和整理好的文字都在，可以搜索、一键复制，只存在你自己电脑上。
- **长录音**：一次最长 20 分钟。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| 按住**右 ⌥**（Windows：**右 Ctrl**） | 说话，松手出字 |
| 单击这个键 | 切换模式：点一下开始，再点一下完成 |
| 按住**左 ⌥**（Windows：**右 Alt**） | 语音操控：让电脑替你做 |
| **Esc** | 取消录音 / 关掉胶囊上的提示卡片 |

快捷键都可以在「设置 → 快捷键」里改。

## 系统要求

- macOS 12 及以上（Apple 芯片或 Intel）
- Windows 10 / 11（x64 或 ARM）
- 需要联网（语音在杭州、新加坡两地的服务器上处理）

## 隐私

- 录音只用来识别出文字，我们不保存录音。
- 历史记录只存在你自己电脑上，可以在设置里关掉。
- 「我的词库」存在你的账号里，只用来提高你自己的识别准确率。
